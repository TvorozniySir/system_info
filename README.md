Скрипт `system_info.py` определяет, в какой ОС он запущен (Linux или Windows), собирает информацию о системе и сохраняет её в файл `system_info.json`.


## Как работает
1. Через `sys.platform` определяется ОС.
2. Для Linux данные читаются из файлов `/proc` и `/etc/os-release`.
3. Для Windows данные берутся из `sys.getwindowsversion()` и переменных окружения.
4. Размеры и время переводятся в понятный вид (например, `3.91 GB`).
5. Результат записывается в JSON.

Используются только стандартные модули `sys`, `os`, `json`.
